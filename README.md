# Vipasana

A quiet companion for [Vipassana](https://www.dhamma.org/) practice: watch the natural breath (Anapana), name vedana as pleasant / unpleasant / neutral, and receive gentle alerts through the day.

Everything stays on your device. There is no account and no server.

## Practice

- **Today** — minutes sat, breaths counted, check-ins, sit streak, and the next bell
- **Breath** — timed sits (5–60 min). Observe the breath, or optionally let the microphone watch volume so the orb follows inhale and exhale
- **Feel** — a vedana check-in, then a closer feeling, intensity, and where it sits in the body
- **Alerts** — morning sit, midday check-in, evening sit, and short returns to the breath. Browser notifications while the tab is open
- **Journal** — a local record of what arose and passed

This is a practice aid, not a medical device.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
